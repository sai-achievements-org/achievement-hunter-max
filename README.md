# Focus Timer Pro ⏱️

A clean, minimalist, and highly effective Pomodoro-style productivity timer built with Vanilla JavaScript, HTML, and CSS. 

## Features
- **Work Mode:** Standard 25-minute focus blocks.
- **Break Mode:** 5-minute cooldown blocks.
- **Dark Mode UI:** Easy on the eyes with a sleek dark aesthetic.
- **No Dependencies:** Pure HTML/CSS/JS for maximum performance.

## How to use
1. Clone this repository
2. Open `index.html` in your favorite browser
3. Click "Start" and get to work!
